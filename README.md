# Proyecto-de-PostgresSql
Proyecto para la materia de base de datos de la Universidad del valle

Este proyecto es una solución integral para la gestión de servicios de telecomunicaciones, diseñada para automatizar la venta de planes, el registro de clientes y la liquidación de facturación. El sistema permite a una red de empresas asociadas gestionar catálogos de planes, procesar contratos automáticos y controlar el consumo de llamadas en tiempo real

## Requerimientos del proyecto:

Gestión de Clientes:
-La empresa debe permitir registrar y mantener información de los clientes, incluyendo detalles como tipo de documento, número de documento, nombre, apellido, dirección, fecha de nacimiento, sexo, teléfono, ocupación y rango salarial.

Asociación de Planes con Clientes:
-Se debe permitir asociar un plan seleccionado por el cliente, incluyendo el tipo de plan, características del plan, número telefónico único generado y fecha de corte de facturación.

Gestión de Contratos:
-Se debe generar automáticamente un contrato único para cada asociación de plan con cliente, registrando el número de contrato, duración y fecha de inicio.

Registro de Llamadas:
-Registrar las llamadas realizadas por los clientes, incluyendo el número de teléfono abonado, número de teléfono destino, minutos consumidos, fecha, ciudad del abonado, ciudad destino y si la llamada es a otro operador.

Gestión de Empresas Asociadas:
-Se debe permitir registrar y mantener información sobre las empresas asociadas, incluyendo su nombre y ciudad.

Gestión de Planes:
-La empresa debe poder gestionar un catálogo de planes, con detalles como nombre del plan, tipo (prepago/postpago), minutos, gigas, mensajes, precio para prepago, precio del plan para postpago, valor del minuto adicional y descripción.
